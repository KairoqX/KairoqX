## `01` — About Me

I'm **KairoqX**, a student developer interested in understanding how software works beneath the surface.

I enjoy building practical tools, experimenting with Linux, exploring low-level programming, and learning how intelligent systems are built.

- Currently exploring **C, Rust, AI/ML and systems programming**
- Interested in operating systems, developer tools and automation
- Daily environment: **Arch Linux**
- I prefer building things, breaking them, and understanding why they work.
